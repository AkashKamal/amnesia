# Golden query set: what a working software engineer actually types.
#
# Format:  query ||| expected-substring [|| alternative ...] ||| tag
# An empty expectation means "no single right answer; scored for plausibility
# by hand, not by this file".
#
# Expectations are substrings of the COMMAND, matched case-insensitively
# against the top 3 results. They are deliberately loose: "docker ps" is right
# whether or not it carries --all, and pinning exact flags would make this file
# a test of the corpus rather than of the resolver.
